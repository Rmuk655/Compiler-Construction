# Q4: Mini Assignment 6, CS3423: Compilers 2: SSA, Dominators and Post Dominators

The mem2reg pass of LLVM is an optimization where local variables stored in memory (allocas used only by load, store instructions) are removed by 
LLVM (by this pass) and replaced with SSA values, adding phi nodes at the iterated dominance frontiers where different values meet.
This is very beneficial because it reduces the overhead of load/store operations which involve accessing memory, which takes more time as 
compared to register operations. It also puts the IR in SSA form, so later passes like constant propagation, GVN and dead code elimination can 
optimize it further.
