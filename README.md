# Compiler Construction

[![CI](https://github.com/Rmuk655/Compiler-Construction/actions/workflows/ci.yml/badge.svg)](https://github.com/Rmuk655/Compiler-Construction/actions/workflows/ci.yml)

Lexers, parsers, LLVM IR and Clang tooling, organised by topic. Each folder has its own build instructions; generated files (`lex.yy.c`, `lex.yy.cpp`, `*.tab.c`, `*.tab.cpp`, binaries) are not committed and are regenerated by the build.

## Repository layout

### Lexing and parsing — [`Lexing-and-Parsing/`](Lexing-and-Parsing)

| Project | Description | Tools |
|---|---|---|
| [`Tcl-to-Cpp-Transpiler/`](Lexing-and-Parsing/Tcl-to-Cpp-Transpiler) | Lexer/parser conflict analysis and a Tcl → C++ transpiler, with a test suite run in CI | Flex, Bison |
| [`lex-yacc/`](Lexing-and-Parsing/lex-yacc) | An integer-expression calculator (`calculator/`) and a lexer/parser for a small imperative language with declarations, assignments, `print` and `if`/`else` (`mini-language/`, with sample input and outputs) | Flex, Bison |
| [`lex-yacc-mini-language-skeleton/`](Lexing-and-Parsing/lex-yacc-mini-language-skeleton) | Starting skeleton for the mini-language (question, partial lexer/parser, sample input); the worked solution is `lex-yacc/mini-language` | Flex, Bison |

### LLVM IR — [`LLVM-IR/`](LLVM-IR)

| Project | Description | Tools |
|---|---|---|
| [`LLVM-IR-Explorer/`](LLVM-IR/LLVM-IR-Explorer) | C/C++ programs and the LLVM IR Clang 17.0.6 generates for them: globals, control flow, functions, casts, data structures, floating point; includes a written report | Clang, LLVM |
| [`llvm-ir-and-cfg/`](LLVM-IR/llvm-ir-and-cfg) | C++ → LLVM IR (`ir-basics/`), plus control-flow-graph dumps for `foo`/`bar` and a dead-code experiment (`cfg-and-pass/`) | Clang, `opt`, Graphviz |

### Kaleidoscope front end — [`Kaleidoscope/`](Kaleidoscope)

| Project | Description | Tools |
|---|---|---|

| [`kaleidoscope-flex-bison-baseline/`](Kaleidoscope/kaleidoscope-flex-bison-baseline) | Earlier flex/bison version of the same front end | Flex, Bison, LLVM |

## Toolchain setup

Tested on Ubuntu (WSL2).

```bash
# Flex / Bison / build tools
sudo apt update && sudo apt install -y flex bison build-essential cmake git graphviz

# LLVM 14 from apt
sudo apt install -y llvm-14 llvm-14-dev clang-14 lld-14
clang-14 --version && opt-14 --version && llvm-config-14 --version

# LLVM / Clang 17.0.6 from source (used for the Clang tooling and LLVM-IR-Explorer)
git clone https://github.com/llvm/llvm-project.git && cd llvm-project
git checkout llvmorg-17.0.6
mkdir build && cd build
cmake -G "Unix Makefiles" -DLLVM_TARGETS_TO_BUILD=X86 \
      -DLLVM_ENABLE_PROJECTS="clang;clang-tools-extra" -DCMAKE_BUILD_TYPE=Release ../llvm
make -j$(nproc)
```

Useful references: [Kaleidoscope tutorial](https://github.com/sreevyshnavi02/kaleidoscope_tutorial), [`llvm::Value`](https://llvm.org/doxygen/classllvm_1_1Value.html), [AST Matcher reference](https://clang.llvm.org/docs/LibASTMatchersReference.html).

## Building and running

```bash
# Lex/Yacc calculator
cd Lexing-and-Parsing/lex-yacc/calculator
bison -d parser.y -o parser.tab.c && flex lexer.l && gcc parser.tab.c lex.yy.c -o calc

# Kaleidoscope front end (needs LLVM and clang++); IR and diagnostics go to stderr
cd Kaleidoscope/kaleidoscope-frontend
make && ./toy < tests.kal 2>&1

# Emit LLVM IR and a control-flow graph for a C file
cd LLVM-IR/llvm-ir-and-cfg/cfg-and-pass
clang -S -emit-llvm -O0 -Xclang -disable-O0-optnone -fno-discard-value-names temp.c -o temp.ll
opt -passes=dot-cfg temp.ll -disable-output && dot -Tpdf .foo.dot -o foo.pdf
```

Other IR commands: `clang -S -g -emit-llvm temp.c -o temp.ll` (with debug info) and `clang -S -emit-llvm -Xclang -disable-O0-optnone temp.c -o temp.ll` (unoptimised, attribute-free).
