# Experiments

| Folder | Lab topic |
|---|---|
| `lex-yacc/calculator` | Basic Lex/Yacc: `+`, `*`, parentheses over integers |
| `lex-yacc/mini-language` | lexer + parser for declarations, assignments, `print`, `if`/`else` (question in `question.md`, sample input `test.eg`, outputs in `output/`) |
| `llvm-ir-and-cfg/ir-basics` | C++ → LLVM IR (`example.cpp`, `example.ll`) |
| `llvm-ir-and-cfg/cfg-and-pass` | CFG dot/PDF dumps for `foo`/`bar` in `temp.c`, plus a dead-code experiment (`ded.ll`) |
| `kaleidoscope-frontend` | Flex/Bison + LLVM IRBuilder front end |
| `clang-ast-matchers` | Clang LibTooling tool (`Simple_Pass`) built with AST matchers; place in `clang-tools-extra/` of an LLVM tree to build |

See `setup-notes.txt` for installation steps and commands.
